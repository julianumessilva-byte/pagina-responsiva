# Desafio CSS Flexbox - Postagens Horizontais

Este repositório contém a solução para o desafio de layout utilizando **CSS Flexbox**.

## 🎯 Objetivos Concluídos

1. **Alteração da direção do Flexbox**: No arquivo `style.css`, o seletor `article` foi configurado com `flex-direction: row`, organizando a imagem, o texto e o botão lado a lado.
2. **Redimensionamento dos Cards**: Propriedade `flex` ajustada para que cada card ocupe `100%` da largura da página.
3. **Alinhamento individual**: Aplicação do `align-self: flex-start` no botão interno (`.card-button`), quebrando o alinhamento centralizado padrão determinado pelo container pai.

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3 (Flexbox)
- JavaScript
